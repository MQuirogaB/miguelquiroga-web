- **[DaFont - Descargar fuentes](https://www.dafont.com/es/)** — Archivo de fuentes de descarga gratuita. Búsqueda por orden alfabético, por estilo, por autor o por popularidad.
- **[LaserCutMazes](https://adashrod.github.io/LaserCutMazes/welcome)** — Generador de laberintos para corte láser.
- **[Jigsaw puzzle](https://gists.rawgit.com/Draradech/35d36347312ca6d0887aa7d55f366e30/raw/b04cf9cd63a59571910cb226226ce2b3ed46af46/jigsaw.html)** — Generador de puzles.
- **[Templatemaker](https://www.templatemaker.nl/en/)** — I charge nothing for the templates. I don't ask for registration on my site either. Yet, this site is a lot of work!
- **[Gallery - Boxes.py](https://boxes.hackerspace-bamberg.de/)** — Boxes.py is an Open Source box generator written in Python. It features both finished parametrized generators as well as a Python API for writing your own. It features finger and (flat) dovetail joints, flex cuts, holes and slots for screws, hinges, gears, pulleys and much more.
- **[MakerCase - Easy Laser Cut Case Design](https://www.makercase.com/#/)** — MakerCase generates box designs for laser cutters and CNC routers and outputs SVG and DXF files ready for cutting.
- **[Reinforced Open Box with Finger Joints](https://cuttle.xyz/@cuttle/Reinforced-Open-Box-with-Finger-Joints-kuXXyUPyimG1)** — On this box the bottom sits slightly higher and slots into the sides so that it's fully supported. This enables it to hold more weight than a "standard" press-fit box.
- **[Curved Wedge Inlay Earrings](https://cuttle.xyz/@cuttle/Curved-Wedge-Inlay-Earrings-gFXPZTXpMb6n)** — Make earrings with contrasting press-fit inlays. The downloaded file will be adjusted based on the kerf value to give the inlay a nice, tight fit.
- **[Cat Face Inlay Earrings](https://cuttle.xyz/@cuttle/Cat-Face-Inlay-Earrings-BhwlGSh34Fr4)** — Make earrings with contrasting press-fit inlays. The downloaded file will be adjusted based on the kerf value to give the inlay a nice, tight fit.
- **[Rounded Teardrop Inlay Earrings](https://cuttle.xyz/@cuttle/Rounded-Teardrop-Inlay-Earrings-E8aplkd4gPhA)** — Make earrings with contrasting press-fit inlays. The downloaded file will be adjusted based on the kerf value to give the inlay a nice, tight fit.
- **[Block of Text Generator](https://cuttle.xyz/@cuttle/Block-of-Text-Generator-qQNRwDWVT9iN)** — Type anything to make a connected "block of text" for a coaster or sign. The text is automatically sized to fit, with optional score lines between letters.
- **[Cardstock Polygon Box](https://cuttle.xyz/@cuttle/Cardstock-Polygon-Box-Ar6cqKXEMfy3)** — This box is cut and scored from a single sheet of cardstock, then folds together. Everything tucks in, no glue required. Optional lid included. You can customize the number of sides, diameter, and height.
- **[Connected Text](https://cuttle.xyz/@cuttle/Connected-Text-29M9IXUSr5yr)** — Connect text together so that it can be cut out in one piece. Dots on i's are automatically joined, letters are pressed together, and so on. It works instantly, and you can use any font!
- **[Walking Man Automaton](https://cuttle.xyz/@cuttle/Walking-Man-Automaton-7ztueWP9CkLU)** — Make this kinetic toy of a walking person out of laser-cut plywood and paper. The base works like a finger-joint box so you can measure your plywood and change the material thickness and kerf to get a nice press fit. Assembly video included.
- **[Name Tags](https://cuttle.xyz/@cuttle/Name-Tags-2NrhKugVpmaW)** — Type your own text to generate laser engravable name tags. The text will auto-scale to fit for longer names.
- **[Keychain Generator](https://cuttle.xyz/@cuttle/Keychain-Generator-j0lMJaBnDHn0)** — A laser cut keychain dangle. Type your own text. Customize the font, sizing, and key ring hole placement.
- **[Emoji Keychain](https://cuttle.xyz/@cuttle/Emoji-Keychain-WT5e0Hmgekwu)** — Like the text keychain generator but with an emoji of your choice. Customize the size, outline, and key ring hole placement.
- **[Garden Markers](https://cuttle.xyz/@cuttle/Garden-Markers-TOlMPZvMlpQw)** — Type your own text for these laser-cut garden stakes.
